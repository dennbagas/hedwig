# PRD: Hedwig — GitHub-Telegram Notification & PR Bot

Hedwig connects GitHub and Telegram, delivered in phases:

- **[Phase 1: Notifications & CI/CD Retry Bot](phase-1-notifications.md)** —
  **shipped**. Relays GitHub repository events to Telegram and offers a retry
  button for failed CI/CD runs.
- **[Phase 2: PR Creation Bot](phase-2-pr-creation.md)** — **redesigned, not
  yet implemented**. A first Telegram-wizard version was built then
  reconsidered; the current plan is a bulk PR-creation flow driven by a
  Google Doc deployment checklist.

See each linked document for that phase's goals, non-goals, user stories,
functional requirements, and technical design.
